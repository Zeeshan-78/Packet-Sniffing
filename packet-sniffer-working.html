Java Packet Sniffer

— HOW IT WORKS — COMPLETE GUIDE —

01 — What is Packet Sniffing?

Jab bhi aap internet use karte ho — website open karo, message bhejo, video dekho — data packets ke form mein travel karta hai network pe.

Ek Packet Sniffer ek aisa tool hai jo in packets ko "capture" karta hai jab woh aapke network interface se guzarte hain — bilkul waise jaise ek security camera sab kuch record karta hai jo samne se guzre.

💡
Normal mode mein network card sirf apne liye aaye packets leta hai. Promiscuous Mode mein woh saare packets capture karta hai — chahe woh kisi ke bhi liye hon.

OSI Model — Packets Kahan Se Aate Hain

🌐 Layer 7 — ApplicationHTTP, DNS, SSH, FTP
📦 Layer 4 — TransportTCP, UDP (Ports)
🔢 Layer 3 — NetworkIP Address (IPv4/IPv6)
🔗 Layer 2 — Data LinkMAC Address, ARP, Ethernet
⚡ Layer 1 — PhysicalActual bits on the wire

Hamara sniffer Layer 2 se upar sab kuch capture karta hai — IP, TCP, UDP, ICMP, ARP, aur application protocols bhi.

02 — How It Works (Simple)

Network Traffic Flow
[ Internet ] ↓ packets travel [ Router / Switch ] ↓ forwards to your machine [ Network Interface (eth0/wlan0) ] ↓ our tool intercepts here ← CAPTURE POINT [ libpcap (low-level OS library) ] ↓ passes raw packet bytes [ Pcap4J (Java wrapper) ] ↓ parses into Java objects [ PacketSniffer.java ] ↓ extracts IP, port, protocol, payload [ Terminal Output + Log File ]

03 — Program Flow (Step by Step)

1
printBanner()

Program start hota hai — ASCII art banner print hoti hai, colors set hote hain ANSI codes se.

2
listInterfaces()

Pcaps.findAllDevs() call hoti hai — OS se saari network interfaces ki list milti hai (eth0, wlan0, lo, etc.) apni IP addresses ke saath.

3
User Settings

User choose karta hai: interface, BPF filter, verbose mode, hex dump, log file, packet limit.

4
nif.openLive()

Network interface Promiscuous Mode mein open hoti hai — ab woh saare packets capture karegi, sirf apne nahi. snapLen=65536 matlab poora packet capture hoga.

5
Capture Loop

handle.getNextPacketEx() baar baar call hoti hai — har baar ek naya packet milta hai jab koi network activity hoti hai.

6
handlePacket()

Packet parse hoti hai: ARP hai? IP hai? TCP/UDP/ICMP? Port numbers se app protocol detect hota hai. Sab kuch terminal pe print hota hai.

7
Ctrl+C → printStats()

Shutdown hook fire hota hai — handle close hota hai, stats print hoti hain, log file save hoti hai.

04 — Pcap4J Library

Java mein directly raw packets access karna possible nahi — OS allow nahi karta. Isliye hum libpcap use karte hain, jo ek C library hai jo OS-level packet capture karta hai.

Pcap4J us C library ka Java wrapper hai — Java code se libpcap functions call hote hain.

// pom.xml mein ye dependency add ki hai:
<dependency>
    <groupId>org.pcap4j</groupId>
    <artifactId>pcap4j-core</artifactId>
    <version>1.8.2</version>
</dependency>

// Ye internally libpcap.so (Linux) ya Npcap.dll (Windows) load karta hai
⚠️
Isliye sudo/root chahiye hota hai — libpcap ko OS kernel se raw packets access karne ke liye elevated permissions chahiye.

05 — Packet Handle

Handle ek "connection" hai aapke program aur network interface ke beech. Ye capture session manage karta hai.

// Interface promiscuous mode mein open karo
PcapHandle handle = nif.openLive(
    65536,                           // snapLen: max bytes per packet
    PromiscuousMode.PROMISCUOUS,    // saare packets capture karo
    10                               // timeout milliseconds
);

// BPF filter lagao (optional)
handle.setFilter("tcp port 80", BpfProgram.BpfCompileMode.OPTIMIZE);

// Loop mein packets lo
while (running) {
    Packet pkt = handle.getNextPacketEx();
    handlePacket(pkt, verbose, showHex);
}

06 — Protocol Detection

Pcap4J har packet ko layer by layer parse karta hai. Hamara code check karta hai konsa protocol hai:

if (packet.contains(ArpPacket.class)) {
    // ARP packet — Layer 2, MAC resolution
    ArpPacket arp = packet.get(ArpPacket.class);
    srcIP = arp.getHeader().getSrcProtocolAddr().getHostAddress();

} else if (packet.contains(IpV4Packet.class)) {
    IpV4Packet ip = packet.get(IpV4Packet.class);
    srcIP = ip.getHeader().getSrcAddr().getHostAddress();

    if (packet.contains(TcpPacket.class)) {
        // TCP — port numbers check karo
        TcpPacket tcp = packet.get(TcpPacket.class);
        int dstPort = tcp.getHeader().getDstPort().valueAsInt();

    } else if (packet.contains(UdpPacket.class)) {
        // UDP — connectionless protocol

    } else if (packet.contains(IcmpV4CommonPacket.class)) {
        // ICMP — ping, traceroute
    }
}

07 — BPF Filters

Berkeley Packet Filter — ye ek powerful filter language hai jo OS level pe hi packets filter karta hai, program mein aane se pehle. Isse performance bahut better hoti hai.

// Sirf HTTP traffic
"tcp port 80"

// Sirf DNS queries
"udp port 53"

// Ek specific IP se/ko
"host 192.168.1.1"

// SSH ke ilawa sab kuch
"not port 22"

// Sirf ping packets
"icmp"

// Ek IP ka sirf HTTP
"host 192.168.1.5 and tcp port 80"

// Koi bhi traffic local se bahar
"src net 192.168.1.0/24"
✅
Filter agar nahi doge toh saare packets capture honge — busy network pe ye bahut zyada output de sakta hai. Specific filter use karo jab possible ho.

Build Karo

mvn package
3
Run Karo (root chahiye)
